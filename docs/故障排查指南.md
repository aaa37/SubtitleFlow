# 故障排查

| 情况 | 可执行处理 |
|---|---|
| 提示 ffmpeg / ffprobe / whisper-cli 缺失 | 重新解压完整 ZIP。到设置选择完整发行包 `_internal/vendor`，点击重新检查；不要只复制主 EXE。 |
| 程序无法启动 | 确认 Windows x64，检查文件来源/校验值。重新解压到个人目录。向客服提供系统版本、报错截图；不要关闭安全防护。 |
| 模型下载失败 / 没有网络 | 检查网络后重试，或从官方仓库下载 base/small 多语言 bin 后 GUI 导入。不要重命名其他模型冒充。 |
| 模型校验失败 | 当前内容与固定官方哈希不符，不会安装。删除自行下载的错误文件，再下载匹配版本；旧的有效模型不会被坏下载覆盖。 |
| 视频没有音轨 | 在播放器确认声音，选择带语音音轨的文件。静音画面不能产生真实语音字幕。 |
| 文件损坏 / 不支持编码 | 先用播放器检查是否完整，重新获取原文件；查看详细错误，避免整个批次重试。 |
| 权限不足 / 文件占用 | 关闭正在使用字幕的编辑软件，选择自己的 Documents / 桌面等有权限目录；不要写入 Program Files。 |
| 磁盘空间不足 | 清理系统临时目录所在磁盘和输出目录所在磁盘。16kHz 单声道 PCM 约每分钟 1.9 MB，超长文件需额外空间。 |
| whisper.cpp 异常退出 | 关闭其他高内存软件，改用 base，重启程序。保留本地错误日志供客服排查。 |
| 正在识别看起来没动 | CPU 模型耗时没有固定比例，界面仍可操作。可取消当前或停止全部。 |
| 编辑数据找不到 | 保留与字幕同名的 `.subtitleflow.json`；已经删除时可重新转写，当前不支持任意外部 SRT 导入编辑。 |
| 处理时关闭窗口 | 确认退出后软件终止子进程、等待后台清理。网络准备可能等待约 20 秒的超时，不要强制关机。 |

日志入口：设置 → 打开本地数据 / 日志。日志只在本机生成，可能包含路径和引擎诊断片段。发送前检查并遮盖个人信息；程序不会自动发送日志。
