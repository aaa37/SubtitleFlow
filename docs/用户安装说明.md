# 字幕工坊 · 用户安装说明

本说明面向通过验收后的 Windows 发行包。当前源码交付不是已验证的正式商品；购买页面应说明实际交付状态。

## 适用电脑

Windows 10 1903 或更新版本 / Windows 11，64 位 x64 处理器。无需 NVIDIA 显卡。建议先使用 base 模型，small 模型占用更多内存、处理时间也可能更长。没有公布经过实测的最低内存或处理速度，请卖家提供对应版本的试用结果。

## 安装

1. 将 ZIP 下载到自己的磁盘；核对卖家提供的文件名和 SHA-256（如需，使用 Windows 文件校验工具）。
2. 右键 ZIP → 全部解压。不要在压缩包内部直接打开程序，也不要只复制 EXE。
3. 双击解压后 SubtitleFlow 文件夹内的 SubtitleFlow.exe。不需要安装 Python、FFmpeg 或输入命令。
4. 首次打开会检查组件、模型、输出目录和空间。模型未准备是正常情况。
5. 前往「模型管理」，点击 base 的「下载 / 重试」。显示校验通过后返回批量字幕。

未签名候选版可能出现系统信誉提示。先确认卖家身份、文件来源与校验值；不建议关闭系统安全防护。正式发行版的签名状态应由卖家明确说明。

## 不方便联网时

在可联网设备上访问 https://huggingface.co/ggerganov/whisper.cpp ，下载 `ggml-base.bin` 或 `ggml-small.bin`，拷到电脑后点击「导入本地模型」。软件校验完整性，不接收不匹配模型。该站点在部分网络环境可能不可达；产品不承诺所有国内网络均可直接下载。

## 数据位置与卸载

模型、配置、日志和最近 500 条历史记录保存在 `%LOCALAPPDATA%/SubtitleFlow`。输出字幕保存在你指定的目录。删除解压文件夹即可移除程序；如需清除模型及历史，可通过「设置 → 打开本地数据 / 日志」打开位置，退出程序后手动删除该数据目录。不要误删自己的字幕和媒体文件。
