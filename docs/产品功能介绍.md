# 字幕工坊基础版 · 功能介绍

把重复导入、提取音轨、识别和保存步骤整合到中文桌面工作流。

已实现的产品能力（Windows 最终兼容性待验收）：

- 一次导入多个常见音视频，支持拖拽和递归添加文件夹。
- 中文、英文和自动检测；base / small 官方多语言模型。
- 图形下载/导入、完整 SHA-256 校验、失败重试。
- FFmpeg 提取音频，whisper.cpp CPU 本地识别，模型就绪后可断网。
- 每个文件导出 SRT / VTT / TXT，自选目录，避免同名覆盖。
- 串行任务队列，失败继续、取消当前、停止全部、历史记录。
- 表格编辑字幕文本和时间，保存前备份原字幕。

当前不含说话人分离、字幕烧录、云端服务、OCR、复杂时间轴、术语词典、自动样式、在线支付、DRM。增强版预留代码接口不代表功能已开放。
