# 架构与设计

GUI 仅收集参数和显示结果。QThread 工作对象处理导入、环境检查、模型下载和批处理；所有进度、结果与错误经 GUI 线程中的 QObject CallbackBridge 槽转发，即使业务回调是普通 Python 函数，也不会在工作线程内操作界面。业务适配器不依赖 Qt，可注入 ProcessRunner 或 Mock 模型/音视频层。批次串行执行，避免同时载入多份模型导致内存峰值。

处理阶段：检查模型完整性与目录 → ffprobe 读取时长/音轨 → 独立临时目录中提取 16kHz 单声道 PCM → whisper-cli 导出带毫秒偏移的 JSON → 验证分段 → 生成 UTF-8 SRT/VTT/TXT → 写入历史。没有字幕文本时报告失败，不生成伪结果。

取消采用 threading.Event；子进程调用使用可执行文件绝对路径和参数数组。Linux/macOS 独立进程组，Windows 隐藏控制台并 taskkill /T /F 终止子树，再 wait 回收。使用队列读取输出，避免 stdout 堵塞。没有 shell=True。

导出以独占创建预留全组文件名，再原子替换单个文件；失败回滚本次拥有的路径。不能承诺系统掉电时多个不同格式文件同时事务提交。编辑前输出独立备份。历史与配置临时写入后原子替换。进程被强制结束时仍可能留下临时文件，不能声称断电绝不丢失。

进度分三个含义：音频提取百分比来自 ffmpeg out_time_us / 媒体时长；识别只显示阶段；总体是已结束文件数 / 批次总数，失败/取消也计为结束。模型下载是已接收字节 / 固定官方字节数，随后验证 SHA-256。

设计系统：深蓝导航 #101c33、主按钮 #2563eb、背景 #f4f6fa、主要文字 #152742、次要文字 #63738b。间距以 8/14/16/24/30 为主，控件圆角 6/7、面板 10/12。Windows 微软雅黑 UI，macOS 苹方，Linux Noto CJK；Qt 默认支持高 DPI。图标为自绘对话框字幕标识；按钮文字明确表达操作。

增强能力通过 SubtitleTransform 协议串入字幕处理；Entitlements 只预留接口，BasicEdition 仅声明基础功能。没有虚假的在线授权校验。未来增加模块应经过本地性能和质量验证，不应为 49 元基础版引入账号服务器。

0.1.1 后台任务改用有限生命周期 TaskThread：一个原生线程对象执行工作，所有结果通过 GUI CallbackBridge 交付。finished 后先 wait()，再从活动任务中移除并延迟删除，关闭窗口不会跨越未完成的线程清理。15 轮窗口销毁/垃圾回收回归用于覆盖退出顺序。
