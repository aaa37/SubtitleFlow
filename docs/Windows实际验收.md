# Windows 成品验收

本说明是方法，不是通过记录。保留实际输出，不以空表或 Mock 代替实测。

在没有预装 Python/FFmpeg 的 Windows 电脑上解压候选包。验收人员可运行 scripts/windows_acceptance.ps1，传入 AppFolder、官方 ggml-base.bin 和 tests/fixtures/speech-original.wav。脚本调用冻结程序，输出系统、签名状态、程序哈希、真实字幕。普通客户不需要使用脚本。

图形操作逐项检查：

- Windows 10/11，100%、150%、200% 缩放没有遮挡。
- 中文系统用户名、中文解压/输入/输出路径、同名文件、总长超过 260 的路径。
- GUI 准备 base/small 后断网，批量生成 SRT/VTT/TXT。
- 坏文件、空文件、无音轨混入批次，其他文件继续成功。
- 提取/识别时切换页面、取消当前、停止全部、关闭窗口，无遗留子进程。
- 编辑文字/时间并保存；占用其中一个输出时，保存失败可以还原，备份与原文件字节一致。
- 缺组件、低空间、无权限和下载中断时，修复后可重试。
- 按开源库替换说明进行兼容 Qt 库替换，复测 GUI/识别。

尚未执行 Windows runner 或 Windows 真机验收，不能勾选通过。签名导致 EXE 哈希改变时须重新执行冻结测试。
