# 五步生成字幕

1. **准备模型**：打开「模型管理」，先下载速度优先 base。进度显示真实接收量；完整 SHA-256 校验通过后可用。下载中断时可点击下载重试，或导入官方模型，不支持断点续传。
2. **添加文件**：回到「批量字幕」，拖入一个或多个视频，也可添加文件夹。支持 MP4、MOV、MKV、MP3、WAV、M4A。文件夹会包含子目录，重复文件不会再次添加。
3. **选择参数**：普通中文视频选择“中文”，多语种内容可选“自动检测”。选择 base 或 small 多语言模型。勾选 SRT、VTT、TXT 中需要的格式，选择有写入权限的输出目录。
4. **开始生成**：点击「开始生成」，程序会依次检查、提取音频、识别、保存。识别使用本机 CPU；不要根据视频时长推断完成时间。单个文件失败后自动继续，点击「查看失败原因」了解原因。取消当前会继续下一项，停止全部会结束整个队列。
5. **检查与编辑**：生成后打开输出目录。双击已完成任务，修改文本或开始/结束时间，再保存。时间采用 `00:00:01,500` 格式；结束必须晚于开始，行按开始时间排序。保存前保留一份原字幕备份。

SRT 适合多数剪辑软件，VTT 适合网页播放器，TXT 仅含文本。程序会自动避免覆盖同名文件。输出目录下的 `.subtitleflow.json` 是编辑数据，保留它才能从历史任务重新编辑。

## 隐私与离线

下载/导入模型后可断网处理。音视频与字幕不上传，不需要账号。首次下载模型时仅访问官方模型存储服务；对方可见正常下载连接信息。

## 环境提示

缺少处理组件时请重新解压完整发行包，或到「设置」选择完整包的 vendor 目录（通常在 `_internal/vendor`）。不要自行下载陌生 EXE。磁盘不足时先清理临时磁盘/输出磁盘；无音轨视频不能识别语音。

本软件采用 whisper.cpp、OpenAI Whisper、FFmpeg、Qt for Python 等第三方开源技术。模型可能漏字、错字或在静音/音乐中产生错误文本，发布前请人工复核。暂不提供视频烧录字幕、说话人分离、在线激活或云端加速。
