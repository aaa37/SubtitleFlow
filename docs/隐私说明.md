# 隐私说明 · 0.1.0

音视频识别、音轨提取、字幕编辑与导出都在本机执行。本软件没有上传媒体、字幕或日志的接口，不需要账号，不含广告、遥测、在线激活或服务器数据库。

主动点击模型下载时会访问 Hugging Face 官方仓库及其重定向存储节点。这些服务可以看到下载所需的 IP 地址、请求时间等连接信息；软件不在此请求中附带视频或字幕。也可以通过 GUI 导入已下载的官方模型。点击官方页面等外部链接时由浏览器打开，对应网站适用自己的隐私条款。

本机保存：模型权重、输出目录/组件设置、最近 500 条任务历史（含媒体路径、输出路径、错误原因）、滚动日志。日志最大约 8 MB，可能包含引擎诊断片段；请在手动分享前检查敏感信息。软件不自动向客服发送内容。

任务使用独立临时音频目录，正常完成、失败和取消后清理。进程被强制结束或系统断电可能留下系统临时文件，用户可通过系统清理工具处理。输出字幕与编辑数据不会自动删除。模型准备完成后，核心功能可离线使用。

卸载：退出后删除软件文件夹；若希望清除本地配置/历史/模型，再删除 `%LOCALAPPDATA%/SubtitleFlow`。自己的媒体和字幕由用户保管。
