# 更换 LGPL 动态库及重新构建

软件采用 onedir 分发，没有对 Qt/PySide 库做加密、不可替换校验或在线激活。允许为行使 LGPL 权利而修改、替换库，并为调试该修改进行必要的逆向工程。

发行脚本将校验过的 QtBase、QtSvg、PySide/Shiboken、FFmpeg、whisper.cpp 对应源档放入 OpenSource/sources，并将应用源码和重建脚本放入 OpenSource/application-source.zip。普通用户运行软件不需要编译这些材料。

1. 备份整个目录并退出程序。
2. 从对应源码构建兼容 Windows x64、Release、Qt 6.8 ABI 的动态库。QtBase 包含 Core/Gui/Widgets，SVG 插件对应 QtSvg。PySide/Shiboken 构建参考各自源码 README。
3. 在 `_internal/PySide6/` 定位 DLL 及 plugins，替换匹配库；修改了绑定时同步替换兼容 PySide6/Shiboken6 模块。以实际发行包文件清单为准。
4. 启动 SubtitleFlow.exe，检查主界面、导入、编辑及真实转写；失败时还原备份。发行方须保留实际替换验证记录。
5. 可解压应用源码，按 BUILDING.md 重新构建并修改必要适配代码，以便调试和运行修改后的 LGPL 库。第三方组件按各自许可分发，不以应用层商品条款限制这些权利。

当前没有执行 Windows 库替换测试，本说明不代表已验收通过。
