# 常见问题 FAQ

**需要购买 AI API 吗？** 不需要；识别在本机进行。首次模型准备需要联网，或导入已下载的官方模型。

**是否需要 Python / 显卡？** 完整 Windows 发行包自带运行组件。客户不需要 Python，不强制 NVIDIA GPU。当前优先 CPU。

**哪种模型适合中文？** 两种都使用 multilingual 模型。建议先尝试 base；small 一般需要更多资源。软件不下载英语专用 `.en` 模型。

**识别是不是百分之百准确？** 不是。口音、噪声、音乐、重叠发言都影响结果；请校对后发布。界面可以修改文本和时间。

**会覆盖原视频或同名字幕吗？** 不修改原视频。新建输出使用递增编号保护同名文件。编辑保存只覆盖该任务的导出字幕，保存前备份旧字幕。

**下载慢或失败怎么办？** 检查网络后点击重试，或在其他设备从官方模型仓库下载后通过 GUI 导入。当前中断后重新下载，不提供不可靠的续传。

**没有字幕为什么？** 查看失败原因，检查是否没有音轨、文件损坏、语音太少、组件/模型缺失或空间不足。

**识别为什么没有百分比？** 当前引擎适配只报告正在识别，未计算可验证的实时识别百分比。提取阶段显示实际进度；总体显示已结束任务数。

**支持自动把字幕压到视频里吗？** 当前不支持。请将 SRT/VTT 导入常用剪辑软件。

**授权和售后是什么？** 基础产品计划一次性定价 49 元；最终许可、客服渠道和服务范围需由卖家在正式销售前填妥。软件目前没有联网授权或防拷贝机制。
