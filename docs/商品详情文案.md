# 字幕工坊｜Windows 本地批量字幕工具

**一次添加多个视频，批量生成字幕。中文界面，本地处理。基础版一次性 49 元。**

适合需要为自媒体、课程录屏、访谈或知识分享整理语音字幕的个人创作者。

把视频拖进软件，选择中文和模型，点击开始生成；程序依次提取声音、识别语音、保存字幕，减少重复操作。每个视频可生成 SRT、VTT 和 TXT，方便导入剪辑软件或继续整理文稿。

**本地识别，自己掌握文件。** 无需账号或收费 AI API。首次下载或导入模型后，可断网转写；软件不上传视频、声音或字幕。

**普通用户也能操作。** 完整 Windows 工具包自带处理组件，不需要安装 Python、FFmpeg 或输入命令。首次通过中文界面准备模型，下载后会做完整校验。

**便于检查和修改。** 支持批量排队、单个失败继续、取消任务、打开输出目录。识别结果可编辑文字和时间，保存前留备份。

购买前请确认：使用 Windows 10 1903 及以上或 Windows 11 x64；本版 CPU 本地处理，速度受电脑、模型和视频内容影响。模型下载站点可能在部分网络不可达，也可从官方页面下载后导入。口音、噪声、音乐和多人同时讲话可能导致错误，字幕请人工复核。本版不包含字幕烧录到视频、云端加速或说话人区分。

交付：Windows ZIP 便携包、中文使用说明、首次使用教程、FAQ、故障排查和第三方开源声明。软件使用 whisper.cpp / OpenAI Whisper、FFmpeg、Qt 等第三方技术，提供中文桌面交互与批处理封装。
